This repo is all about exploring Supreme Court decisions using graph structures. It creates a visual representation of cases and their relationships. It leverages D3.js for dynamic visualizations and Node.js for backend processing.

## Key Components:
- **D3.js**: For rendering interactive graphs.
- **Node.js**: Handles data retrieval and server actions.
- **Express**: Sets up the web server.

## Getting Started:
1. Clone the repo:
   ```bash
   git clone https://github.com/justin-napolitano/sup-court-graph-explore.git
   cd sup-court-graph-explore
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the server:
   ```bash
   npm start
   ```

## Gotchas:
- Ensure you have Node.js installed (v14+ recommended).
- The dataset may take a bit of time to load, especially on first run. Be patient!
